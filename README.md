# MY580: Agentic AI for Social Science and Data Science Research

This repo contains materials for the MY580 agentic AI workshop at LSE.

## Primary tooling

Students will work hands-on with a free, terminal-based agentic AI coding assistant — **[Gemini CLI](https://github.com/google-gemini/gemini-cli)** — and use it to explore how modern AI agents plan, use tools, and execute multi-step tasks.

Note to future users: Gemini CLI is free as of May 2026. There is no guarantee it will still be free in the future. The principles in this workshop are intended for general agentic AI use, not specifically Gemini.

If you already use another agentic AI, or have a higher tier account with a different vendor (Anthropic, Open AI), feel free to use that.

We will also use python and R, and you should have a modern IDE installed ([Positron](https://positron.posit.co/download.html) is my recommendation). 

## Setting up Gemini CLI

If you hope to use Gemini CLI for the workshop, please install it on your laptop ahead of time using the guide for your operating system:

- [Windows setup](./gemini-cli-setup-windows.md)
- [macOS setup](./gemini-cli-setup-mac.md)

Each guide takes ~10 minutes and only needs to be done once. You'll need:

- A laptop you can install software on
- A **personal** Google account (for access to the free tier)
- Internet access
